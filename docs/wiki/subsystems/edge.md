# Edge subsystem

> **Layer 2 · Subsystems** — what runs at (or on behalf of) the factory: PLC readers, the
> SparkPlug B agent, the on-prem edge box and its offline mode, and the tools CS uses to reach
> and deploy that box. For engineers onboarding a client or debugging "no data from the plant".
> Up: [Architecture overview](../architecture/overview.md)

## Purpose

The edge subsystem turns values sitting in a factory PLC into a SparkPlug B stream (or a
raw-tag HTTP envelope) that the cloud [ingestion subsystem](ingestion.md) can decode. It owns
three jobs:

1. **Read** the PLCs (Siemens S7, Modbus TCP, OPC-UA) on a poll interval.
2. **Transmit** the readings: assign SparkPlug aliases, publish NBIRTH/NDATA/NDEATH, buffer
   through outages, and cross the WAN (HTTPS or mTLS MQTT).
3. **Operate the box**: enroll it in AWS SSM, push generated bundles, open shells, and
   optionally keep the shop floor seeing and operating during an internet outage.

The design rule since ADR-0042 is a *separated edge gateway*: the reader is
"SparkPlug-ignorant" (it only emits named readings) and one uniform agent owns every
SparkPlug detail.

## Boundaries

**Owns**

- The PLC read path and its per-client config (`client.yaml`, `reader.config.json`).
- The raw-tag wire contract (`edge/raw/<tenant>` loopback topic and `POST /v1/tags`).
- The SparkPlug B edge-node session (`sparkplug-agent`), including the cloud-hosted
  *shared* agent that terminates the HTTPS tee.
- The factory box: SSM hybrid activation, generated compose bundles, on-prem offline stack
  (`compose.onprem-edge.yml`), the edge-operator write-forward design.
- Simulators, twins and fixtures that stand in for a factory on staging.
- Box access: `edge-session-broker` (browser shell / web-UI proxy into the box).

**Does not own**

- SparkPlug **decoding**, the counter state machine (`calc_production_counters`, including
  the `***TRIG*` suffix semantics), RabbitMQ publishing — see
  [sparkplug-decoder](../components/sparkplug-decoder.md) and [ingestion](ingestion.md).
- `packml_register` resolution of topic → `id_equipment` (cloud side).
- OEE math (stream-engine / DB), operator SPA code, edge-api business logic.
- The onboarding *descriptor* UX in csadmin (it only consumes the generated artifacts).

## How it works

Three edge shapes exist today. All end at the same cloud decoder.

```text
 (A) THIN READER + SHARED CLOUD AGENT  (Bispharma box; the edge-api "Go-live" default)
 PLC --S7/Modbus--> packiot-edge-reader --HTTPS POST /v1/tags, X-Ingest-Key-->
     nginx ingest.staging:8449 --> sparkplug-agent-shared (app box, multi-tenant)
         --SparkPlug B--> mosquitto (cloud) --> sparkplug-decoder --> RabbitMQ

 (B) FULL EDGE BUNDLE, ADR-0042 Mode-B  (docs/clients/edge-deployment/compose.edge.yml)
 PLC --> Go readers or Node-RED reader flow --edge/raw/<tenant> or POST :9104-->
     sparkplug-agent (on box) --ssl:// :8883 mTLS, CN=<tenant>--> prod mosquitto
         --> sparkplug-decoder

 (C) ON-PREM OFFLINE ADD-ON, ADR-0053  (compose.onprem-edge.yml, beside shape A)
 packiot-edge-reader --best-effort POST 127.0.0.1:9104--> onprem-agent
     --> onprem-mosquitto --> onprem-transformer (LOCAL_DECODE_ONLY)
         --> SQLite current-state --> edge-dashboard :8080 (floor browser)
```

Inside every agent the flow is the same: raw tag → resolve suffix against `raw_tag_map`
→ report-by-exception store → every tick (5 s) build NDATA → SQLite outbox → uplink
publishes QoS 1 after a rebirth-then-drain on (re)connect. Details in
[sparkplug-agent](../components/sparkplug-agent.md).

Control plane (all outbound from the box, no inbound firewall holes):

```text
 csadmin --> edge-api /api/edge-ssm/* --AWS SSM (CreateActivation, SendCommand,
                                         StartSession)--> amazon-ssm-agent on box (mi-...)
                  \--ws/http--> edge-session-broker --session-manager-plugin--> box shell/UI
```

## Interfaces

| Direction | Protocol / endpoint | Producer → consumer | Notes |
|---|---|---|---|
| PLC read | S7comm ISO-on-TCP :102, Modbus TCP :502, OPC-UA `opc.tcp://` | reader → PLC | Poll every 5 s (Go default) |
| Loopback raw tags | MQTT topic `edge/raw/<tenant>`, JSON `{endpoint, scan_ts, tags[]}` | Go readers → agent | QoS 0, not retained |
| HTTP raw tags | `POST /v1/tags` on :9104, header `X-Ingest-Key` | reader / Node-RED flow / tee → agent | 202 `{accepted,total}`; 401 bad key; 403 unknown group |
| Legacy numeric counters | `POST /v1/counters` on :9104 | numeric tee → agent | Only with `AGENT_NUMERIC_INGEST_ENABLED=true` |
| Public ingest (staging) | `https://ingest.staging.packiot.app:8449/v1/tags` | box reader → nginx → `sparkplug-agent-shared` | SG admits each box's egress /32 |
| CPACK tee (staging) | `https://cpack-ingest.staging.packiot.app:8447/v2/tags` | CPACK factory flow → shared agent (nginx injects `X-Ingest-Group: CPACK`) | `/v1/tags` returns 444 |
| SparkPlug out | `spBv1.0/<GROUP>/{NBIRTH,NDATA,NDEATH}/<edge_node_id>` | agent → mosquitto | NBIRTH retained QoS 1; NDATA QoS 1 |
| Rebirth request in | `spBv1.0/<GROUP>/NCMD/<edge_node_id>` metric `Node Control/Rebirth` | decoder → agent | Agent re-publishes NBIRTH |
| WAN mTLS (prod) | `ssl://ingest.prod.packiot.app:8883` | box agent → prod mosquitto | Cert CN = tenant |
| Box control | AWS SSM RunCommand / Session Manager | edge-api → box | Tags `enterprise=<id>`, `managed-by=packiot-edge-api` |

!!! warning "Prod broker tenant ACL not wired"
    `configs/mosquitto/prod-ingest.acl` scopes each mTLS client (CN = tenant) to
    `spBv1.0/<CN>/#`, but it is loaded only by `configs/mosquitto/mosquitto-prod-ingest.conf`.
    `compose.production.yml` mounts `mosquitto.prod.conf`, which has `require_certificate` and
    `use_identity_as_username` but **no `acl_file`**. As shipped, any client with a valid cert
    can publish under any group. See [brokers](../components/brokers.md).
| Floor dashboard | `http://<box>:${DASHBOARD_PORT}` (`/api/state`, `/healthz`) | browser → edge-dashboard | Works with no internet |

## Data it owns

| Data | Where | Lifecycle |
|---|---|---|
| Agent outbox (encoded NDATA) | SQLite `OUTBOX_PATH` (default `/var/lib/edge-transformer/agent-outbox.db`); multi-tenant `AGENT_OUTBOX_DIR/<group>.db` | Row deleted on PUBACK; cap 100,000 rows, drop-oldest |
| Reader spool (raw batches) | Box host dir `./spool` → `/var/lib/packiot/spool` | One JSON file per failed batch, replayed oldest-first, cap 20,000 files |
| Local current state | SQLite `current-state.db`, table `current_state (tenant, source, metric)` | UPSERT, newest wins; never drained to cloud |
| Tenant agent configs | `docs/clients/tenants/*.yaml` (shared agent), `docs/clients/cpack-agent.yaml`, box `onprem/agent.yaml` | Generated by onboarding (`onboard-gen` / edge-api); pushed by `apply-agent-config` |
| Reader configs | `<tenant>-client.yaml` (Go readers), `reader.config.json` (Python reader) | Generated from the client descriptor `plc:` block |
| Twin totalizer state | Volume `bispharma-twin-state` (`/var/lib/bispharma-twin/totalizers.json`) | Survives restart so totals stay monotonic |

## Configuration that matters

| Knob | Where | Effect |
|---|---|---|
| `RAW_EMIT` (default `true`) | readers | `true` = raw-tag envelopes to `edge/raw/<tenant>`; `false` = legacy direct SparkPlug, single endpoint |
| `PLC_HOST_<ENDPOINT>` | reader env | Per-PLC host; falls back to `S7_HOST` / `MODBUS_HOST` / `OPCUA_ENDPOINT_URL` |
| `AGENT_TENANTS_DIR` vs `AGENT_CONFIG` | agent | Multi-tenant (one pipeline per `*.yaml`) vs single-file mode |
| `AGENT_BIRTH_ALL_MAPPED` (default `true`) | agent | NBIRTH covers the full `raw_tag_map`, so idle lines are aliased up front |
| `AGENT_HTTP_INGEST_ENABLED` + `AGENT_INGEST_API_KEY` | agent | Mounts `/v1/tags`; enabled without a key exits at boot |
| `AGENT_TAGMAP_FROM_REGISTER` (default `false`) | agent | Build the tag map from `packml_register`; needs DB access, so never on a factory box |
| `descriptor.onprem_offline`, `descriptor.operator_edge` | `client_descriptors` | Turn on the on-prem stack / edge-operator service at deploy |
| `SSM_SANDBOX_ENTERPRISE_IDS` (default `2000003`) + any id ≥ 2,000,000 | edge-api | Mutating box ops are mocked for twin tenants |
| `BISPHARMA_TWIN_ENABLED` (default `false`) | staging `.env` | Starts the Bispharma twin; must be off when the real feed is live |

## Failure modes & signals

| Symptom | Likely cause | Where to look |
|---|---|---|
| `accepted:0` on every POST, agent healthy | Reader metric suffix ≠ agent `metric_suffix` keys (exact match only) | `sparkplug_agent_unmapped_tags_total`, `/healthz` `unmapped_tags` |
| 401 on the tee | Wrong `X-Ingest-Key` (cloud key vs `AGENT_INGEST_API_KEY`) | agent log `rejected_auth`, `sparkplug_agent_http_ingest_total{outcome}` |
| 403 on the tee | Group not loaded in `sparkplug-agent-shared` (no tenant yaml) | agent log `unknown group`; run `apply-agent-config` |
| Cloud sees a line only after a restart | Sparse line never aliased → NDATA references unknown alias | Keep `AGENT_BIRTH_ALL_MAPPED=true` |
| Floor dashboard blank, cloud fine | Local tee broken (network split or key) | reader log `local tee POST failed`; see [edge-box](../components/edge-box.md#failure-modes) |
| Totalizer spikes, net = gross on a line | A second writer on real tenant topics (fixture/twin) | [simulators-and-twins](../components/simulators-and-twins.md#failure-modes) |
| Box ops 503 | `SSM_HYBRID_INSTANCE_ROLE` unset, or box not tagged | edge-api logs; `aws ssm describe-instance-information` |
