# sparkplug-agent

> **Layer 3 · Components** — the SparkPlug B edge-node process (ADR-0042 "Tier 2") that turns
> raw named readings into a SparkPlug session. Covers the single-tenant and multi-tenant modes,
> every env var, the outbox, and the known failure modes. For engineers deploying or debugging
> an agent on a box or on the staging app host.
> Up: [Edge subsystem](../subsystems/edge.md)

## Responsibility

The agent is accountable for **one tenant's SparkPlug B edge-node session** (or several
isolated ones in multi-tenant mode): accept raw tags, map each suffix to a full metric name and
datatype through `raw_tag_map`, assign and freeze aliases in an NBIRTH, publish changed values
as NDATA, announce death with an MQTT Last-Will NDEATH, and never lose an encoded NDATA while
the uplink is down. The cloud [sparkplug-decoder](sparkplug-decoder.md) decodes its output
exactly as it decodes any other SparkPlug producer.

## Inputs & outputs

| Direction | Endpoint | Detail |
|---|---|---|
| In (MQTT, single-file only) | `sparkplug.internal_broker` + `sparkplug.raw_topic` (e.g. `edge/raw/cpack/#`) | QoS 0; body = raw-tag envelope (`internal/agent/rawtag`) |
| In (HTTP) | `POST /v1/tags` on `:9104` | Header `X-Ingest-Key` (constant-time compare); body ≤ 1 MiB (`AGENT_INGEST_MAX_BODY_BYTES`). Multi mode routes by body `group`, falling back to header `X-Ingest-Group` |
| In (HTTP, optional) | `POST /v1/counters` | Legacy `{group, gateway, timestamp, counterData[{id,value}]}`; each numeric id → the count-leaf suffix `…/<X>Count/<id>/Unit` in `raw_tag_map` |
| In (MQTT) | `spBv1.0/<GROUP>/NCMD/<edge_node_id>` | `Node Control/Rebirth = true` → re-publish NBIRTH (`sparkplug_agent_rebirths_total`) |
| Out | `spBv1.0/<GROUP>/NBIRTH/<edge_node_id>` | Retained, QoS 1, seq 0, full alias table + `bdSeq` |
| Out | `spBv1.0/<GROUP>/NDATA/<edge_node_id>` | QoS 1, alias-only, changed values only (report-by-exception) |
| Out | `spBv1.0/<GROUP>/NDEATH/<edge_node_id>` | MQTT Last-Will, QoS 1, carries the same `bdSeq` as the birth |
| DB (optional) | `client_descriptors`, `packml_register`, `capture_observations` in the analytics DB | Only with `AGENT_TAGMAP_FROM_REGISTER` / `AGENT_CAPTURE_ENABLED` |

HTTP responses: `202 {"status":"accepted","accepted":N,"total":M}`; `401` bad/missing key;
`403` unknown / missing / out-of-scope group; `400` empty, oversized or undecodable body.
`accepted < total` is **not** an error: the extra tags were unmapped and dropped with a metric.

## Internal design

```text
             ┌─────────────── one "pipeline" per tenant ───────────────┐
 raw MQTT ─┐ │ derive (profile) ─ counter-derive ─ param decomposition   │
 /v1/tags ─┼►│   → resolver.Resolve(suffix)  miss → dropped{unmapped}    │
/v1/counters┘│   → tagstore.Apply (last value + dirty set)               │
             │ tick (AGENT_TICK_SEC=5s):                                 │
             │   DrainDirty → new tag? → Rebirth (skip NDATA this tick)  │
             │              → else BuildNDATA → Encode → outbox.Enqueue  │
             │ uplink goroutine: connect(LWT=NDEATH) → onConnect sets    │
             │   pendingRebirth → drainLoop(1s): NBIRTH then drain FIFO  │
             └────────────────────────────────────────────────────────────┘
```

**Packages**

| Package | Role |
|---|---|
| `internal/agent/agentcfg` | Loads/validates `agent.yaml` (`sparkplug:` block + `raw_tag_map`); register-driven map (`register_pg.go`); cutover status reads |
| `internal/agent/rawmqtt` | Internal-broker subscriber, bounded queue, stale detection (default 60 s) |
| `internal/agent/httpingest` | `/v1/tags`, `/v1/counters`; single-scope guard vs multi-tenant router |
| `internal/agent/tagstore` | Last-value cache + dirty set (RBE), keyed by suffix |
| `internal/agent/aliasmap` | Per-group alias allocation, never shared across tenants |
| `internal/agent/session` | NBIRTH / NDATA / NDEATH builder; seq mod 256, `bdSeq` mod 256 advanced per connection |
| `internal/agent/uplink` | paho publisher, Last-Will, rebirth-then-drain, NCMD rebirth, mTLS (`tls.go`) |
| `internal/outbox` | SQLite (modernc, WAL) FIFO; capacity 100,000, drop-oldest on overflow |
| `internal/agent/deriver`, `counterderive`, `tenantprofile` | Synthesize counts (integral/sum/expr, gross/net/scrap) and decompose `/Status/Parameter` by PackML id |
| `internal/agent/unmapped` | Per-segment unmapped-tag counter + throttled WARN |
| `internal/agent/capture` | Live-capture recorder writing count-index observations for onboarding |
| `internal/agent/onboardapi` | `POST /v1/onboard/generate` (descriptor → artifacts) |

**Metric naming.** Full name = `sparkplug.packml_topic` + `metric_suffix` (or an explicit
`name`). The resolver is an **exact-key map** on `metric_suffix`: no prefix or suffix
tolerance. Datatype comes from the entry's `type`.

**Birth-all-mapped** (default on). NBIRTH contains *every* `raw_tag_map` entry in
suffix-sorted order, unseen ones as SparkPlug nulls, so aliases are stable and a line that was
idle at connect is decodable the moment it reports. With it off, NBIRTH contains only tags
seen so far and a brand-new tag triggers a rebirth.

**Rebirth-then-drain** (ADR-0042 §2.5). On every (re)connect the drain loop publishes a fresh
NBIRTH *before* draining buffered NDATA, because buffered NDATA references aliases that only
that birth defines. The drain is the only reader of the outbox (single-drainer invariant).

**Single-file vs multi-tenant**

| | Single-file (`AGENT_CONFIG` / `--config`) | Multi-tenant (`AGENT_TENANTS_DIR`) |
|---|---|---|
| Tenants | 1 | one per `*.yaml`, keyed by upper-cased `group_id` |
| Raw MQTT subscriber | yes | **no** (HTTP only) |
| Register-driven tag map, param decomposition, derive | yes | no (static map only) |
| Counter-derive, birth-all-mapped | yes | yes |
| Live capture | yes | yes (profiles from `AGENT_TENANTS_PROFILE_DIR`) |
| mTLS uplink | `AGENT_UPLINK_TLS_*` | none (server-auth only if `ssl://`) |
| Outbox | `OUTBOX_PATH` | `AGENT_OUTBOX_DIR/<group>.db` |
| Bad config | exit 1 | file skipped, `sparkplug_agent_tenant_load_failed_total{file,reason}`; exit 1 only if the dir is unreadable or **no** file loads |
| Uplink health | critical (fails liveness) | readiness only (one tenant's broker blip cannot restart the process) |
| Duplicate `group_id` / `edge_node_id` | n/a | first file wins, later ones skipped |

### Environment

| Env | Default | Effect |
|---|---|---|
| `AGENT_CONFIG` or `--config <path>` | — | Single-file config path |
| `AGENT_TENANTS_DIR` | *(empty)* | Set ⇒ multi-tenant mode |
| `AGENT_OUTBOX_DIR` | `/var/lib/edge-transformer/outbox` | Multi-tenant outbox dir |
| `OUTBOX_PATH` | `/var/lib/edge-transformer/agent-outbox.db` | Single-file outbox |
| `AGENT_TICK_SEC` | `5` | NDATA cadence |
| `HEALTH_PORT` | `9103` | `/healthz` + `/metrics` |
| `LOG_LEVEL` | `info` | slog level |
| `MQTT_STALE_THRESHOLD_SECONDS` | unset ⇒ 60 s | `≤0` disables "no raw tags received" degradation (set `-1` where tags come only via HTTP) |
| `AGENT_HTTP_INGEST_ENABLED` | `false` | Mount `/v1/tags` |
| `AGENT_INGEST_API_KEY` | — | Required when ingest is enabled; empty ⇒ exit 1 |
| `AGENT_INGEST_PORT` | `9104` | Ingest listener |
| `AGENT_INGEST_MAX_BODY_BYTES` | `0` ⇒ 1 MiB | Body cap |
| `AGENT_NUMERIC_INGEST_ENABLED` | `false` | Mount `/v1/counters` (single-file only); fails if `raw_tag_map` has no count leaves |
| `AGENT_BIRTH_ALL_MAPPED` | `true` | Full-map NBIRTH |
| `EMIT_DEFINITIVE_BIRTH` | `false` | NBIRTH counter metrics carry role-typed properties (ADR-0046) |
| `AGENT_UNMAPPED_VERBOSE` | `false` | Log every unmapped suffix instead of a throttled summary |
| `AGENT_UPLINK_TLS_CERT` / `_KEY` / `AGENT_UPLINK_CA` | — | mTLS files for an `ssl://` uplink. Setting them against a plaintext broker makes the TLS handshake time out |
| `AGENT_TAGMAP_FROM_REGISTER` | `false` | Build `raw_tag_map` from `packml_register` + profile. Needs `AGENT_PROFILE_PATH` and DB access; **never on a factory box** |
| `AGENT_PROFILE_PATH` | — | Tenant profile (`tenantprofile`) |
| `AGENT_PARAM_DECOMPOSITION` | `false` | Rewrite bare `/Status/Parameter` + PackML id to `ParameterNNNNN`; needs a profile with `parameter_decomposition.source_leaf` whose tenant matches `group_id` |
| `AGENT_CAPTURE_ENABLED` | `false` | Live capture (records count indices while the tenant's `client_descriptors.status='captured'`) |
| `AGENT_CAPTURE_FLUSH_SEC` / `AGENT_CAPTURE_STATUS_POLL_SEC` | `30` / `300` | Capture flush and status-poll intervals |
| `AGENT_TENANTS_PROFILE_DIR` | — | Multi-tenant capture profiles |
| `AGENT_REGISTER_DSN` | — | DSN for register/capture; else built from `DB_USER`, `DB_PASSWORD`, `DB_HOST`(`postgres`), `DB_PORT`(`5432`), `DB_NAME`(`packiot`), `DB_SSLMODE`(`disable`) |
| `ONBOARD_API_ENABLED` / `ONBOARD_API_KEY` / `ONBOARD_API_PORT` | `false` / — / `9105` | Onboard generate API; enabled without a key ⇒ exit 1 |

Staging values (`sparkplug-agent-shared`): `AGENT_HTTP_INGEST_ENABLED=true`,
`MQTT_STALE_THRESHOLD_SECONDS=-1`, `AGENT_CAPTURE_ENABLED=true` (default in compose),
`AGENT_TENANTS_PROFILE_DIR=/etc/packiot/tenant-profiles`, `mem_limit 192m`, `cpus 0.50`;
`AGENT_INGEST_API_KEY` and `AGENT_REGISTER_DSN` come from `/opt/packiot/.env`.

### `agent.yaml`

```yaml
sparkplug:
  group_id: CPACK                 # SparkPlug group = tenant
  edge_node_id: cpack-tee         # must be distinct from any other producer of this group
  packml_topic: CPACK/SC          # prefix prepended to every metric_suffix
  internal_broker: tcp://mosquitto:1883
  raw_topic: edge/raw/cpack/#
  uplink_broker: tcp://mosquitto:1883   # ssl://ingest.prod.packiot.app:8883 on a Mode-B box
  uplink_tls_cert_ref: ""               # secret refs (resolved out of band)
raw_tag_map:
  - {metric_suffix: /CELULA1/CER400/CER400/Admin/ProdProcessedCount/107/Unit, type: double}
  # optional per entry: name (explicit full name), device_key (ADR-0046),
  # counter_derive (gross/net/scrap synthesis mode)
```

`type` ∈ `double` (default) · `float` · `long` (Int64) · `int` (Int32) · `bool` · `string`.

Real files: `docs/clients/tenants/cpack.yaml` (79 entries, prefix `CPACK/SC`),
`docs/clients/tenants/bispharma.yaml` (663 entries, group `BISPHARMASTAGING`),
`docs/clients/cpack-agent.yaml` (102 entries, prefix `CPACK/SC/LINHAS`). They are generated by
`onboard-gen` / edge-api from the client descriptor — regenerate, do not hand-edit.

## Data & invariants

- **Tenant isolation.** Aliases, dirty sets, birth state and outboxes never cross the tenant
  seam. In multi mode a POST is routed only to the pipeline whose `group_id` matches.
- **Exactly one producer per `(group, edge_node_id)`.** Two agents (or an agent and a sim)
  publishing the same metric names under the same group double-count downstream. Note that
  `docs/clients/tenants/cpack.yaml` and `docs/clients/cpack-agent.yaml` both declare
  `CPACK/cpack-tee`: run only one of the `shared-tee` / `cpack-tee` profiles.
- **Durability.** An NDATA is on disk (outbox) before it is published; rows are deleted only
  after PUBACK. Overflow (100,000 rows) drops the *oldest*.
- **Ordering.** NBIRTH precedes any NDATA of the same connection; NDATA drains FIFO.
- **Auth is never optional.** Every HTTP front-door fails closed without a key.

## Failure modes

| Failure | Symptom | Cause | Fix |
|---|---|---|---|
| Every tag rejected | `accepted:0` on every frame, unmapped counter climbs | Reader suffix split ≠ agent `metric_suffix` (CPACK 2026-08-18: reader `/L5/...`, generated agent `/LINHAS/L5/...`) | Deploy reader and agent as a matched pair from one descriptor; diff the live box map before swapping |
| Doubled metric names | `BISPHARMASTAGING/SP/SP/LINHAS/…`, no `equipment_values` | Stale `packml_topic` after the descriptor prefix changed (Bispharma, 2026-09-02); deploy did not regenerate agent configs | Regenerate every derived artifact in the same deploy |
| Sparse lines undecodable at the cloud | `ErrUnknownAlias` on NDATA of lines idle at connect | Seen-only NBIRTH (CPACK 2026-08-13) | `AGENT_BIRTH_ALL_MAPPED=true` (default since 2026-08-20) |
| Crash-loop at boot on a box | TLS `connect timeout` | `AGENT_UPLINK_TLS_*` set while the uplink is plaintext `tcp://` (sandbox replica, 2026-08-31) | Leave the TLS env empty for a loopback uplink |
| Crash-loop at boot on a box | DB dial errors | `AGENT_TAGMAP_FROM_REGISTER=true` on a factory box that cannot reach the cloud DB | Keep it `false` at the edge |
| Crash-loop, uplink key unreadable | TLS load error | Key file not readable by uid 65532 | `chown 65532:65532 uplink-key.pem` (see `compose.edge.yml` comment) |
| 403 for a new client | `unknown group` | Tenant yaml not in the shared agent's dir | edge-api `POST /api/edge-ssm/apply-agent-config` (pushes the yaml to the app box and recreates the service) |
| Counter baseline lost after a cloud restart | Decoder logs "sequence gap", line goes dark | Agent never reconnected so never rebirthed (seen on CPACK L5/TEXA) | Decoder now sends a Rebirth NCMD; check `sparkplug_agent_rebirths_total` increments |
| One tenant file malformed | That tenant missing, others fine | Blast-radius isolation | Fix the file; watch `tenant_load_failed_total` |

## Operating it

- **Staging shared agent:**
  `docker compose -f compose.staging.yml --profile shared-tee up -d sparkplug-agent-shared`.
  New tenant = add `docs/clients/tenants/<t>.yaml` and **recreate** the service (tenant files
  are read at boot).
- **Probe:** `curl -s localhost:9103/healthz | jq`, `curl -s localhost:9103/metrics | grep sparkplug_agent_`.
- **Synthetic POST** (staging, from the app box network):
  `curl -X POST -H "X-Ingest-Key: $KEY" -d '{"group":"...","endpoint":"probe","scan_ts":...,"tags":[...]}' http://172.18.0.44:9104/v1/tags`.
  A synthetic count can spike a real totalizer; delete the probe rows afterwards.
- **Safe:** restart (outbox and rebirth-on-connect make it lossless for buffered data).
  **Unsafe:** running two agents with the same `group_id`/`edge_node_id`; deleting the outbox
  volume while the uplink is down (buffered data is lost).
